**Course Outcome (CO2)** 

Design and implement software solutions that effectively address user requirements and enhance system reliability and performance. 

**Program Outcome (PO3)** Design and Development of Software Solutions 

# **Assessment Tool** 

Project Design Report, GitHub Repository, MVP Demonstration, Individual Viva 

# **Lab Overview** 

In this lab, each team will work as an independent **software development company** . Your team has been awarded a software development contract from a client. The client has provided a project scenario describing a real-world problem. 

Your responsibility is to: 

- Analyze the client's requirements. 

- Select the most appropriate software development process model. 

- Design the proposed software solution. 

- Develop a **Minimum Viable Product (MVP)** demonstrating the core functionality. 

- Collaborate professionally using Git and GitHub. 

- Document your engineering decisions in a Project Design Report. 

This is **not a complete software development project** . Instead, it is the first milestone of a semester-long project where each lab builds upon the previous one. 

# **Learning Outcomes** 

After completing this lab, students will be able to: 

- Analyze a real-world software engineering problem. 

- Identify stakeholders and user requirements. 

- Differentiate among software process models. 

- Select and justify an appropriate software development methodology. 

- Plan software development collaboratively. 

- Develop a small functional prototype (MVP). 

- Apply Git and GitHub in collaborative software development. 

- Produce professional software engineering documentation. 

# **Project Assignment** 

- Students will work in **teams of three members** . 

- Each team will continue working on the **same project** throughout the semester. 

- Teams may use **any programming language, framework, database, IDE, or development platform** . 

# **Laboratory Activities** 

# **Phase 1 – Requirement Analysis** 

Analyze the assigned project and identify the client's needs. Complete the following: 

- Project overview 

- Problem statement 

- Stakeholder identification 

- Project scope 

- Functional requirements (minimum 10) 

- Non-functional requirements (minimum 8) 

- Five user stories or use cases 

- Assumptions and constraints

# **Phase 2 – Software Process Model Selection** 

Study the following software process models: 

- Waterfall 

- Incremental 

- Prototype 

- Spiral 

- Rapid Application Development (RAD) 

- Agile XP 

- Scrum 

- Kanban 

Based on your project characteristics: 

- Select **one** software process model. 

- Justify your selection. 

- Discuss why the chosen model is suitable. 

- Explain why at least **two alternative models** are less suitable. 

There is **no single correct answer** . Your reasoning and justification will be evaluated. 

# **Phase 3 – MVP Design and Development** 

Develop a **Minimum Viable Product (MVP)** that demonstrates the feasibility of your proposed software solution. 

The MVP should include only the essential functionalities required to demonstrate the project concept. 

Examples include: 

- User authentication 

- Dashboard 

- One or two core modules 

- Basic CRUD operations 

- Navigation between pages 

- Sample data management 

- Simple user interface 

The MVP should remain **small, functional, and modular** . Teams should focus on applying software engineering principles rather than implementing numerous features. 

# **Phase 4 – GitHub Collaboration** 

Each team will maintain a shared GitHub repository. Every team member must contribute individually using Git. Recommended workflow: main │ ├── member1-feature ├── member2-feature └── member3-feature 

Each member must: 

- Create a feature branch 

- Implement assigned tasks 

- Commit changes with meaningful messages 

- Push changes to GitHub 

- Create Pull Requests 

- Review teammates' code 

- Resolve conflicts if necessary 

- Merge approved changes into the main branch 

The repository history should clearly demonstrate each member's contribution.
